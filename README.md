# SS9-Co-operate

*Nine stars, one hidden code — and the sky's own way of working: to cooperate.*

オリオン座の7つの星に、シリウスとプロキオンを加えて9つ。 その星空の奥に隠された「コード」を証明しようとしたところから、この試みは始まりました。 競争と協調を同時に生きる **Coopetate（Coopetition）** を根に、 理論・物理・経済・社会・協創を、一本の系譜でつなぎます。

**名の起点 →** [seven-stars-9code](https://github.com/kiki054-n/seven-stars-9code)

すべてのリポジトリには共通タグ `ss9co` が付いています。 [**エコシステム全体を一覧する**](https://github.com/search?q=user%3Akiki054-n+topic%3Ass9co&type=repositories)（各群は `topic:群名` で絞り込めます）
